Google Places API Anahtari

Google Places kaynagini kullanmak icin kendi ucretsiz Google Maps API anahtarinizi girmeniz gerekiyor. Anahtar sadece bu tarayicida saklanir, hicbir yere kaydedilmez.

  1. Google Cloud Console'da yeni bir proje olusturun (ucretsiz).
  2. Places API (New) sayfasindan API'yi etkinlestirin.
  3. Credentials sayfasindan "Create Credentials > API Key" ile anahtarinizi olusturun.
  4. Anahtari asagiya yapistirin.

Vezno Isletme Tarayici

Koordinat / mahalle ve yaricap girin, taramak istediginiz isletme turunu secin.
